# AI_Lister — Releases

Public host for the **eBay AI Lister** desktop app updates. Contains only:

- **`latest.json`** — the manifest the app checks on launch (version, download URL, notes).
- **Releases** — the `.dmg` installers, attached as release assets.

No source code lives here. See the private `AI_Lister` repo's `RELEASING.md` for the
release workflow.
